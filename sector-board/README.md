## 全市场实时层（v3.9，`/live.json`）

- 成员表：`docs/assets/universe-data.js` 提供 5,584 只代码、32 个申万行业、138 个概念和 11 个周期主题的成员映射；由 Host 静态路由提供，不额外请求。
- 轮询：交易时段（09:15–11:30、13:00–15:00）每 15 秒把全市场按 300 只一组拆成 22 批并行请求 `/live.json?codes=...`；非交易时段只拉一次最近快照。
- 浏览器聚合：用全市场报价重算市场宽度（涨跌家数/涨跌停/中位/均涨）、行业/概念/主题平均涨跌、情绪分，并回填所有展示价格；今日 pulse、ribbon、板块页、概念热点、周期表都随之更新。
- 全 tab 回填：价格/涨跌/成交额/换手/量比写回今日、板块、盘中、模拟盘、更多与个股抽屉；ribbon 交易中显示 `分析日期 · 行情 HH:MM:SS`，休市显示 `分析日期 · 已收盘`。
- 规则：跌停撬板（上一快照在跌停价、当前离开跌停 ≥0.5%）、涨停打开（上一快照在涨停价、当前跌破 0.2%）、急拉/急跌（相邻快照 ≥1.5%）；同一股票同一类型 2 分钟内只记一次。
- 分析边界：技术信号（MA/MACD/RSI）、周期阶段、决策候选/风险、龙虎榜/红利/事件仍来自每日 ETL；界面用「全市场 15 秒 · 分析每日」区分，不把日频分析伪装成实时。
- 其他轮询：模拟盘 `/paper.json` 与更多页 `/global.json` 每 10 秒；`dashboard.json` 每 5 分钟检测新快照。
- 展示：左侧异动列表 + 右侧监控表（按涨跌幅/涨速/量比/成交额排序）。不写文件、不推微信。

## 周期机会排序与公司公告（v3.9）

- **周期机会优先**：板块页 11 个周期主题按机会分降序，机会分 = 状态基准分 + 5 年/1 年分位修正；每行显示「机会 / 关注 / 中性 / 回避」标签和一行「为什么有机会」（5 年分位、1 年分位、近 5 日、今日、首个先行指标）；右侧详情有机会卡、机会分和完整理由，再往下才是出清链条、政策、ETF、龙头。
- **公司公告脚本**：`announcements.py` 从东方财富公告接口抓取（巨潮资讯兜底），默认关注池来自 dashboard 的决策候选/风险、主题前 3、龙虎榜/游资和模拟盘持仓；输出 `~/.dsh/sector-board/announcements.json`。
  - 默认：`python3 announcements.py --days 120 --limit-per-code 12`
  - 指定股票：`python3 announcements.py --codes 600519,000001 --days 180 --limit-per-code 20`
  - 合并追加：`python3 announcements.py --codes 300750 --merge`
  - 面板接口：`GET /api/sector-board/announcements.json?code=600519`；未命中缓存时 Host 会按需调用脚本并合并。个股抽屉底部显示最近 5–8 条公告，点击打开原文；接口失败显示错误，不伪造公告。

## 机器人交易员（模拟盘，`robot.py`）

从决策页的「底部反转龙头」候选里自动买卖，账户与 `paper.py` 共用 `~/.dsh/sector-board/paper.json`。

- 硬约束：最多 3 只、单只 ≤34%、100 股/份取整、双边费 0.05% 与滑点 0.05%、浮亏 -8% 强制卖出。
- 决策来源：优先调用 opencode（CLI 或 HTTP），不可用时退回确定性规则，并在 `decisions[].mode` 标明。
- 自动运行：launchd `com.sly.sector-robot`，工作日 14:50；日志 `~/.dsh/sector-board/robot.log`。
- 手动运行：`python3 robot.py --run`；`--dry-run` 只看不落账；`--rules` 强制规则；`--status` 查看账户。
- 安全闸：周末、行情日期非今日（节假日）、dashboard 超过 7 天未更新时拒绝交易并写原因。
- 接入 opencode（已配置）：
  - `~/.dsh/sector-board/robot.env` 当前指向 OpenCode.app 内置 CLI：
    `OPENCODE_BIN=/Applications/OpenCode.app/Contents/Resources/opencode-cli`，
    `OPENCODE_MODEL=opencode/deepseek-v4.1-flash-free`。
  - 换模型：`opencode models` 看可用模型，改 `OPENCODE_MODEL` 即可；不需要重启 DSH。
  - 也可改用 `OPENCODE_API_KEY` + `OPENCODE_BASE_URL` 走 HTTP。
- 面板「机器人」页：模式、上次/下次运行、本轮成交与被拒原因、观察名单；持仓与净值每 10 秒刷新。

## 技术分析（个股抽屉）

任何出现股票名的地方（决策候选、总览成分股、主题成分股、热点榜）都能打开「技术分析」抽屉：

- 日线 / 周线 / 月线切换；周/月线取 5 年数据聚合。
- 蜡烛图 + MA5/10/20/60 + 布林上下轨（20,2）+ 成交量（VMA5）+ MACD；鼠标悬停显示当日 OHLC、涨跌幅、成交量。
- 状态分 0–100（强势/偏强/震荡/偏弱/弱势）只描述趋势结构，不是胜率；信号标签列出均线排列、站上 MA20/60、MACD 水上/水下、近 5 日金叉/死叉、RSI 超买超卖、KDJ 钝化、放量、20 日新高新低、布林突破、1 年位置。
- 指标卡：MA 距离、RSI6/14、KDJ、布林上中下、ATR14（含占价格 %）、1 年位置、20/60/120 日高低温。
- 「技术解读」按规则生成 3–5 条描述，不生成买卖建议。
- 已知限制：日线来自新浪，**不复权**，除权日会出现跳空，均线/MACD 会被短暂扰动；后续切换前复权源。

## 口径

### 总览（技术信号）

| 信号 | 条件 |
|---|---|
| 水上金叉 | MACD(12,26,9) 今日 DIF 上穿 DEA，且 DIF、DEA 均 > 0 |
| 水下金叉 | 同上，但 DIF、DEA 均 < 0 |
| 近期大涨 | 近 5 日涨幅 ≥ +10% |
| 近期大跌 | 近 5 日涨幅 ≤ -10% |
| 大跌后横盘 | 近 20 日跌幅 ≤ -12%，近 5 日振幅 ≤ 6%，且近 5 日涨跌幅绝对值 ≤ 3% |
| 周期底部 | 收盘价在近 250 日分位 ≤ 10% |
| 周期高点 | 收盘价在近 250 日分位 ≥ 90% |

涨跌停按板块：主板 9.8%、创业板/科创板 19.6%、北交所 29.4%。

### 龙虎榜 / 游资

- 龙虎榜：东财 `RPT_DAILYBILLBOARD_DETAILSNEW`，当日全部上榜股，展开看买卖席位（`RPT_BILLBOARD_DAILYDETAILSBUY`）。
- 游资：龙虎榜里剔除「机构专用」席位后的买卖净额；净买入 > 0 才上榜。活跃营业部按买入额取前 20。

### 板块周期

- 周期行业（申万一级 12 个）：有色金属、钢铁、煤炭、石油石化、基础化工、建筑材料、房地产、农林牧渔、交通运输、机械设备、电力设备、国防军工。
- PE/PB 中位数：东财 `RPT_VALUEANALYSIS_DET` 当日快照（PE_TTM / PB_MRQ），剔除负值与空值。
- 估值横分位：行业 PE 中位数在 12 个周期行业中的百分位。
- 小周期：成分股近 250 日价格分位中位数；大周期：近 1250 日（约 5 年）价格分位中位数（新浪 1300 根不复权日线）。
- 阶段：底部（大≤35% 且 小≤35%）、顶部（大≥70% 且 小≥70%）、上行（大≤55% 且 小>大+8pct）、下行（大≥45% 且 小<大-8pct）、其余震荡。
- 个股表：行业内 PE 分位、1 年/5 年位置、阶段、5 日涨跌。

### 红利

近 12 个月股息率 ≥ 3%（每股分红/现价）、非 ST、总市值 ≥ 50 亿，按股息率降序取前 120 只。

### 概念板块

- 来源：东财 F10 `CoreConception/PageAjax` 的 `ssbk`，逐股拿全部板块归属，缓存 `board_cache.json`；剔除地域/风格/指数/资金面/涨跌停等噪声，成分 ≥ 5 只，只保留名称含「概念」或主题白名单（猪肉、光伏、影视、白酒、半导体…）。
- 输出 138 个概念板块；每个板块与行业同构（涨跌家数、涨跌停、7 类信号、信号成分股），卡片和详情可直接复用。
- 搜索索引同时收录板块（`type=board`）和股票的板块标签；点搜索结果里的板块会跳到总览概念视图并选中它。

### 信息（事件基准率）

- 事件日期：股指期货交割日 = 每月第三个周五；LPR = 每月 20 日；FOMC = 2022–2026 北京时间决议日（硬编码）；两会 = 3 月 5 日；政治局会议（4/7/10/12 月底）与中央经济工作会议（12 月中）为惯例估计，页面标「惯例估计」。
- 统计：把日期对齐到最近的交易日（±6 天内），以上证指数（sh000001）计算 T-1、当日、T+1、T+5 的涨跌，给出胜率、均值、中位数与样本数。
- 口径限制：样本只有 2022 年以来，事件类日期样本 2–39 个不等；页面明确写「历史频率只解释波动来源，不能直接当预测」，避免把统计当信号。

### 主题周期

- 11 个主题，成员来自概念板块并集（`board_cache`）或申万一级行业：半导体（半导体概念 + 半导体）、CPO/光模块（CPO概念）、机器人（机器人概念 + 人形机器人）、猪肉、影视、光伏、电池（锂电池 + 固态 + 燃料电池）、稀土永磁（概念），房地产/有色金属（申万一级），恒生科技（无 A 股成分，用 513130 代理）。
- 指标：成分数、平均涨跌幅、涨跌家数、涨跌停、小周期（250 日分位中位数）、大周期（1250 日分位中位数）、PE/PB 中位数、主题间 PE 横分位、250 日年化波动、阶段（规则同板块周期）。
- 周期分析由指标生成：位置 + 阶段 + 周期特性（强周期/成长周期/弱周期） + 估值，明确写出「赔率好但需要催化」等条件，不直接给买卖结论。
- 个股技术分析：`/api/sector-board/stock.json?code=` 现算 MA5/10/20/60、MACD、RSI，前端画蜡烛图 + 成交量 + MACD。

### 技术指标（全站）

ETL 在 `analyze()` 里为每只股票算好一套技术快照，随成分股/主题/热点一起下发：

- 均线排列：MA5 > MA10 > MA20 为「多头」，反向为「空头」，其余「纠缠」；同时给 `ma20_dist`（到 20 日线的距离）。
- MACD 区域：DIF、DEA 都在零轴上方为「水上」，都在下方为「水下」，否则「零轴」；金叉与水上/水下金叉信号同源。
- RSI14：≥70 标超买（红），≤30 标超卖（绿）。
- 市场温度卡右侧显示全市场均线多头/空头、MACD 水上、RSI≥70 的只数。

## 本地 OpenAI 兼容桥（opencode_proxy.py）

opencode 的免费额度只对 OpenCode 客户端开放，直接拿它的 HTTP 端点会返回 `FreeUsageLimitError`。
`opencode_proxy.py` 把本机 CLI 包装成 OpenAI 兼容接口，供 DSH 或其它客户端使用：

- 地址：`http://127.0.0.1:8788/v1`
- 模型：`opencode/deepseek-v4.1-flash-free`（改 `robot.env` 的 `OPENCODE_MODEL` 可换）
- 端点：`/v1/models`、`/v1/chat/completions`（支持 stream）
- launchd：`~/Library/LaunchAgents/com.sly.opencode-proxy.plist`（KeepAlive）
- 在 DSH 的「设置 → 模型 → 自定义提供方」里填 Base URL 与任意非空 API Key 即可。
- 限制：不支持工具调用与图片，只做纯文本问答；延迟约 3–20 秒。
