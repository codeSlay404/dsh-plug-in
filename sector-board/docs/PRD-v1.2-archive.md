# PRD · A股板块看板 v1.2（八分区 + 实时 + 模拟盘）

更新:2026-11-16
来源:对话（用户需求）+ 东财 datacenter / 新浪 / 雪球接口实测
状态:v1.2 已实现（2026-11-16 全量跑通：5,578 只股票 / 927 只 ETF / 全球 35 项实时报价 / 模拟盘账户已初始化）

## 1. 背景与目标

v1.0 已上线：DSH 全局面板，按 32 个申万一级行业展示 7 类技术信号（水上/水下金叉、急涨/急跌、大跌后横盘、周期底部/高点）。

v1.1 解决三个缺口：

1. **资金面缺失**：只有价量信号，看不到当天谁在买——补龙虎榜与游资（非机构席位）动向。
2. **周期只有"位置"没有"阶段"**：现有"周期底部/高点"是 250 日分位，缺 5 年大周期、缺估值（PE/PB）维度、缺行业级周期判断。
3. **红利资产没有独立视图**：高股息股票混在行业里，无法单独跟踪。

目标：一个页面看四件事——**板块在什么位置（技术面）、资金在买什么（龙虎榜/游资）、周期在什么阶段（估值+价格）、红利贵不贵**。

## 2. 用户与场景

- 用户：个人 A 股投资者，收盘后复盘 + 盘中看板块轮动。
- 场景：盘后打开看板 → 看哪些板块在底部/顶部、当天龙虎榜资金流向、红利股估值水位；盘中快速确认持仓板块位置。

## 3. 信息架构

顶部一级导航：**总览 | 龙虎榜 | 游资 | 周期 | 红利**

```
总览     v1.0 保留：市场统计 + 7 信号筛选 + 板块卡片 + 右侧股票详情
龙虎榜   当日上榜股票表 + 席位明细（点击展开）
游资     非机构席位净买个股榜 + 活跃营业部榜
周期     周期行业卡片（阶段/估值/5年位置） + 个股周期表
红利     红利股表（股息率/PE/PB/位置） + 板块统计
```

## 4. 功能需求

### 4.1 龙虎榜

- 数据：当日龙虎榜全部上榜股票（东财 `RPT_DAILYBILLBOARD_DETAILSNEW`）。
- 列表字段：代码、名称、涨跌幅、换手率、上榜原因（EXPLANATION）、龙虎榜买入额、卖出额、净买额、净买占成交比、买方席位数量。
- 排序：净买额（默认）、涨跌幅、净买占比。
- 交互：点行展开该股当日买入/卖出前五席位（营业部名、买入额、卖出额、净额、是否机构专用）。
- 空态：当日无数据 / 非交易日 → 显示"最近交易日 YYYY-MM-DD"或"无数据"。

### 4.2 游资关注

定义：**剔除"机构专用"席位后的龙虎榜资金**。

- 个股榜：非机构席位净买额 > 0，按净买额降序；字段：代码、名称、涨跌幅、非机构净买额、非机构买入额占成交比、上榜席位中非机构家数、换手率。
- 活跃营业部榜：当日买入额 top 20；字段：营业部、买入额、卖出额、净额、涉及股票数、涉及股票（前 3）。
- 过滤：ST 股可开关（默认显示）。
- 免责：营业部别名不做猜测，只展示营业部全称。

### 4.3 板块周期

**周期行业清单**（申万一级，可配置）：
有色金属、钢铁、煤炭、石油石化、基础化工、建筑材料、房地产、农林牧渔、交通运输、机械设备、电力设备、国防军工。

每个行业卡片展示：

| 指标 | 定义 |
|---|---|
| 股票数 | 该行业成分股数 |
| PE/PB 中位数 | 成分股 PE_TTM / PB_MRQ 中位数（剔除负值/空值） |
| 估值横向分位 | 行业 PE 中位数在全部 12 个周期行业中的百分位（越低越便宜） |
| 小周期位置 | 成分股"近 250 日价格分位"的中位数 |
| 大周期位置 | 成分股"近 1250 日（约 5 年）价格分位"的中位数 |
| 阶段 | 见 4.3.1 |
| 波动率 | 成分股 250 日日收益波动率中位数（年化） |
| 行业特性 | 强周期 / 弱周期 / 防御（人工标注） |

**4.3.1 阶段判定规则**

```
底部：大周期位置 ≤ 0.35 且 小周期位置 ≤ 0.35
顶部：大周期位置 ≥ 0.70 且 小周期位置 ≥ 0.70
上行：大周期位置 ≤ 0.55 且 小周期位置 > 大周期位置 + 0.08
下行：大周期位置 ≥ 0.45 且 小周期位置 < 大周期位置 - 0.08
其余：震荡（中段）
```

**4.3.2 个股周期表**

点行业卡片 → 该行业成分股表：代码、名称、PE_TTM、PB、行业内估值分位、1 年位置、5 年位置、阶段、近 5 日/20 日涨跌。

- 行业内估值分位：该股 PE_TTM 在同行业成分股中的百分位（0 = 最便宜）。
- 5 年位置：近 1250 个交易日收盘价分位；不足 1250 日按实际长度。

### 4.4 红利板块

- 样本：近 12 个月股息率 ≥ 3%，且非 ST、市值 ≥ 50 亿；按股息率降序，最多 120 只。
- 字段：代码、名称、行业、股息率（近 12 月每股分红/现价）、PE_TTM、PB、1 年位置、近 5 日涨跌、连续分红年数（v1.2）。
- 板块统计：数量、中位股息率、中位 PE、中位 PB、上涨/下跌家数。
- 与周期板块重叠的股票标"周期"标签。

### 4.5 刷新与数据口径

- ETL 每日收盘后跑一次（15:30 后第一次打开自动触发；也可手动「更新数据」）。
- 龙虎榜/估值/分红走东财 datacenter；日线走新浪（长历史）/雪球/腾讯（分级降级）。
- 全部数值带 `as_of` 日期；缺失显示 `—`，不估算。

## 5. 非功能需求

- 全量 ETL ≤ 8 分钟（5578 只）。
- dashboard.json ≤ 5 MB；页面首屏 ≤ 1.5s。
- 面板沿用 DSH 主题 token，不引入外部 UI 库；不写 DOM、不用 iframe。
- 移动端不要求（DSH Web GUI 桌面使用）。

## 12. v1.3 板块与搜索补全（2026-11-17）

### 12.1 问题

- 总览只有 32 个申万一级行业，看不到「猪周期 / 光伏 / 影视」这类概念与细分板块。
- 搜索只匹配名称与代码：搜「猪」无结果，搜「光伏」只有 ETF，体验上等于搜不到股票。

### 12.2 板块数据

- 来源：东财 F10 `CoreConception/PageAjax` 的 `ssbk`，逐股返回全部板块归属（行业层级 + 概念板块）。缓存 `~/.dsh/sector-board/board_cache.json`（code → 板块名列表），增量补齐。
- 过滤：剔除地域、风格、指数、资金面、涨跌停、机构持仓等噪声；成分数 < 5 的板块不展示；与申万一级同名的板块去重。
- 分类：
  - 概念板块：名称含「概念」，或属于主题白名单（猪肉、光伏、影视、机器人、低空经济等）。
  - 行业细分：申万二/三级行业板块（养殖业、光伏设备、影视院线、半导体…）。
- 输出：`dashboard.json.boards = { concept: [...], industry: [...] }`，每个板块与行业同构（count/up/down/flat/limit/signals/lists/avg_pct），可直接复用板块卡片与详情面板。

### 12.3 交互

- 总览工具栏新增分段：申万行业 / 概念板块 / 行业细分；筛选、排序、选中逻辑对三者通用。
- 搜索索引新增 `type='board'` 行与股票的 `tags`（板块归属）；搜索按「名称 > 代码 > 前缀 > 标签包含」打分。
- 搜索结果点板块 → 跳到总览对应模式并选中该板块；点股票/ETF/全球标的 → 打开详情抽屉（实时报价）。

### 12.4 验收

1. 概念板块中能搜到猪肉概念、光伏概念、影视概念，且成分股数量 > 0。

3. 搜「猪」「光伏」「影视」能出现对应板块或股票；点板块能定位。
4. 空数据/旧数据（无 boards 字段）时页面不崩，仅隐藏分段。

## 14. v1.5 从「大盘」转向「股市分析」（2026-11-17）

用户原话（m01895）：不只是大盘，要能做股市分析；①信息板块：期货交割日、议息会议等，历史上这类日期涨还是跌、如何预测；②周期板块：半导体、CPO、猪肉、影视、光伏、电池、恒生科技、机器人、房地产、有色金属、稀土等相似周期放一起，点开弹窗看周期分析，下方可看/搜股票，点股票有技术分析；③机器人模拟盘。

### 14.1 信息（事件日历 + 基准率）

- 事件：股指期货交割日（每月第三个周五）、LPR（每月 20 日）、FOMC（2022–2026 北京时间决议日）、两会（3/5）、政治局会议（4/7/10/12 月底，惯例估计）、中央经济工作会议（12 月中，惯例估计）。
- 统计：上证指数在事件 T-1 / T / T+1 / T+5 的胜率、均值、中位数、样本数；日期先对齐最近交易日（±6 天）。
- 表达：明确「历史频率 ≠ 预测」，事件页只描述历史波动来源，不生成买卖信号。

## 16. v2.0 决策系统（2026-11-17）

用户判断（m02339）：「我不是要你造一个同花顺这样的系统，而是做一个告诉我哪个在底部，那个在高位。什么时候该入场，什么时候该退场。市场情绪在哪里。各种消息面等。」用户参数（m02344）：周级与月级持有、龙头个股、风险约束灵活、核心入场逻辑 = 周期底部出现反转趋势。

### 16.1 原则

- 输出物是**今日结论 3–5 条**，不是行情列表；每条必须有位置证据、触发条件、失效条件。
- 不做假精确评分：候选用规则筛选 + 排序分，页面标注「分数只用于排序，不是胜率」。
- 所有结论可被证伪：给出失效条件；后续按周校准（5/10 日收益 vs 行业基准）。
- 消息面只做确认/否决层，不直接生成买卖。

### 16.2 三层位置判定（P0 用第一层 + 确认层）

| 层 | 指标 | 现状 |
|---|---|---|
| 位置 | 1 年/5 年价格分位、到 MA200 距离、破净率 | 1 年全量；5 年仅主题/周期股 |
| 估值 | PE/PB 历史分位、行业横分位、股息率 | 仅有当日快照与横分位 |
| 确认 | 站上 MA20/60、MACD、放量、相对强度、龙虎榜 | 已有技术字段 |

### 16.3 龙头池与候选规则（P0）

- 龙头池：申万行业内总市值前 40% 且 ≥ 50 亿。
- 底部反转候选：1 年价格分位 ≤ 40%，且收盘 > MA20、MA20 斜率 > 0、量比 ≥ 1.1、MACD 不在水下或当日金叉。
- 高位风险：1 年价格分位 ≥ 75%，且 RSI ≥ 70 或 MACD 死叉。
- 排序分：确认项数量 × 10 +（0.40 − 位置）× 100，仅用于排序。

### 16.4 情绪温度计（P0）

score = 50 + (涨跌家数比 − 0.5) × 80 + (涨停/跌停比 − 0.5) × 20 + 中位涨幅 × 3，clamp 0–100；分档：冰点 < 20、偏冷 < 40、中性 < 60、偏热 < 80、过热 ≥ 80。只给仓位态度（防守/按计划/注意兑现），不预测次日。

### 16.5 状态机（P0 输出文案，P1 落数据）

观察 → 试仓 → 持有 → 减仓 → 退出；切换条件见 16.3 与 MA20/止损规则；每个候选标注当前状态与下一步触发。

### 16.6 分期

- P0：决策首页（情绪 + 3 条结论 + 候选/风险表），替换默认首页。
- P1：5 年分位全量、估值历史分位积累、公告/新闻事件映射、涨停池/两融/成交额分位。
- P2：周度校准（命中率、盈亏比、平均持有天数）、仓位建议、自选/持仓接入。

### 16.7 验收（P0，2026-11-17 已实现）
